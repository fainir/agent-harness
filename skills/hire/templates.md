# Hire templates

## Brief (hires/<role>-<slug>.md)

```
# <Role> for <Company> - <slug>

Why a human: <one line>
Outcome: <what is true when this is done>
Deliverables:
1. <deliverable> - accepted when <criteria>
2. ...
Deadline: <date>. Milestones: <m1 by date, $x>, <m2 by date, $y>
Budget: $<total> (OWNER.md cap: $<cap>)
Inputs we give: <files, links, examples>
Access they get: <repo invite / shared folder / test account> - removed on close
Review: <who checks what, with which skill or criteria>
Platform: <name>. Job URL: <after posting>
Status: hiring | onboarded | in progress | reviewing | done | ended (<reason>)
```

## Job post

```
Title: <Role> for <what> (<fixed price | hourly>)

We need <outcome> for <company, one line>.
Deliverables: <1>, <2>, <3>. Accepted when <criteria>.
Timeline: <start> to <deadline>. Budget: <range or fixed>.
You get: <inputs and access>. We respond within a day.
To apply, answer: (1) <screening question about a similar thing you did, with a link>; (2) <question that shows they read the brief>.
```

## Screening scorecard (1 to 5 each, keep the top three)

| Candidate | Relevant sample | Clear reply | Answered both questions | Rating and history | Price vs cap | Total |
|---|---|---|---|---|---|---|

## Interview message (five questions)

```
Thanks for applying. Five quick questions:
1. Which part of this would you do first, and why?
2. What would you need from us before starting?
3. Show one example closest to this work and what you would change in it today.
4. Your realistic delivery date for milestone 1?
5. Anything in the brief you would push back on?
```

## Onboarding message

```
Welcome. Brief: <link or pasted>. Inputs: <links>. Access: <invite> (test data only).
Milestone 1: <deliverable> by <date>, accepted when <criteria>. Questions: reply here, we answer within a day.
```

## Fix list

```
Thanks, close. Before we accept, three things by <date>:
1. <specific issue, where, expected>
2. ...
```

## Log row (hires/log.md)

`| <date> | <name> | <role> | <platform> | $<cost> | <1 to 5> | yes/no | <one line> |`
